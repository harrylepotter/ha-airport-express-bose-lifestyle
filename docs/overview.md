I turned an old Apple AirPort Express into a Wi-Fi controller for my Bose stereo. Using SSH, we inspected its software and USB driver in memory. The AirPort already knew how to move data to USB printers, so we patched its firmware to recognise my USB serial adapter instead. A small program now translates Home Assistant commands into the Bose’s serial language through a three-wire cable. MQTT connects everything, and the controller starts automatically after rebooting. Power is estimated from acknowledged commands, rather than measured directly. No Raspberry Pi, ESP32 or replacement operating system: just existing hardware doing something new.
